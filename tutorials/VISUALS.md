## Working with Dancers

| Topic | Visual suggestion |
|---|---|
| How do I select dancers? | GIF showing area multi-select (long press + drag rectangle) - completely non-obvious from description alone |

| How do I apply color/shape across formations? | Screenshot of the formation scope selector (current / all previous / all next / custom) |
| How do I assign a name and short name? | Screenshot showing inner text (short name/index) vs. name label below shape - two separate things on screen |

## Priority picks

If only a few visuals are possible, these have the highest impact:

1. **Area multi-select GIF** - completely non-obvious interaction
2. **Core concepts diagram** - mental model for new users
3. **Ghost dancers + paths screenshot** - two abstract concepts in one
4. **Formation presets GIF** - unexpected nearest-position behavior worth showing
5. **PDF export example** - helps set expectations before someone tries it
